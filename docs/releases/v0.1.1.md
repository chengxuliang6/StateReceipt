# StateReceipt v0.1.1

StateReceipt v0.1.1 is the first PyPI release of the Python reference CLI. It does not change the StateReceipt v0.1 specification or receipt semantics.

## Highlights

- Install from PyPI with `python -m pip install statereceipt`.
- Build and publish through reviewed GitHub Actions using PyPI Trusted Publishing.
- Add a rendered architecture and trust-boundary guide.
- Add runnable fresh-Codex and provider-independent cross-assistant integration recipes.
- Add a structured public workflow-feedback issue form.
- Replace the abbreviated license file with the complete Apache License 2.0 text and use an SPDX license expression in package metadata.

## Compatibility

- Python: 3.11, 3.12, 3.13
- Operating systems tested in CI: Ubuntu, Windows, macOS
- Specification: StateReceipt v0.1
- License: Apache-2.0

## Upgrade

```bash
python -m pip install --upgrade statereceipt
```

No receipt migration is required from package version 0.1.0 to 0.1.1.
