# Changelog

All notable changes to StateReceipt will be documented here.

The project follows semantic versioning where practical during the 0.x development series; incompatible specification changes may occur before 1.0 and will be called out explicitly.

## [0.1.0] - 2026-08-13

### Added

- StateReceipt v0.1 draft specification.
- Draft 2020-12 JSON Schema.
- Python reference CLI with `init`, `capture`, `validate`, `verify`, `inspect`, and `diff`.
- SHA-256/SHA-512 artifact integrity checks.
- Git snapshot capture and commit checks.
- Semantic/reference validation.
- Deterministic claim evaluation and artifact-driven staleness detection.
- Optional replay of reproducible command/test evidence.
- Python, FPGA/Verilog, and MATLAB example receipts.
- Unit tests and GitHub Actions CI configuration.
